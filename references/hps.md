# HPS 六问：人为什么不用

按顺序问，**不要跳**。前四问是经理可控的环境，第五问才是技能。

| 顺序 | 问题 | 现场怎么问 | 答"否"时的动作 |
|---|---|---|---|
| ① 标准 | 他知道要做成什么样吗？标准可达成吗？ | "这件活做到什么程度算合格？谁告诉你的？" | 定产出与标准、书面化、当面确认 |
| ② 任务支持 | 有资源、有工具、有时间、不被打断吗？ | "你今天被打断几次？系统卡不卡？扫码枪够吗？" | 补工具/终端/网络、排优先级、减干扰 |
| ③ 结果 | 做好了有好处吗？会不会反而多干活？ | "上个月做得最好的那个人，得到了什么？" | 改考核与奖惩、去掉反向激励 |
| ④ 反馈 | 他多久知道自己干得怎么样？ | "你录错了，多久能知道？谁告诉你？" | 建反馈回路（数据直接给本人、班前会点评） |
| ⑤ 技能 | 他是不会做，还是没机会做？ | "让你带一个新人，多久能上手？" | 培训、教练、SOP、师带徒 |
| ⑥ 个人 | 体力、情绪、能力匹配吗？ | "这活累不累？夜班顶得住吗？" | 调岗、辅助工具、排班优化 |

## 判定规则

- ①–④ 任一为否 → **环境问题**，先改环境，**禁止**把培训写进方案。
- ①–④ 全为是，⑤ 为否 → 才是培训。
- ⑤ 为是，⑥ 为否 → 人岗匹配问题，不是培训问题。
- 六问全为是，绩效仍不达标 → 回到流程层与指标层（多半是流程断点或指标指错）。

## 比例感

经验分布：环境（①–④）约 80%，技能 15–20%，个人能力不到 1%。**所以"培训"通常是最后一张牌，不是第一张。**

## 现场访谈话术（10 分钟版）

1. "这件活你一天做几次？"（建立具体场景）
2. "做到什么程度算好？谁定的？"（①）
3. "中间会不会被叫走/等东西/系统卡？"（②）
4. "做好了有人知道吗？有什么好处？"（③）
5. "做错了，多久知道？"（④）
6. "有没有人教过你怎么做？"（⑤）

## 环境改造清单（拿去就能改）

- 工位加终端/扫码枪；网络盲区补 AP
- 报工从"下班补录"改成"工序结束即扫"
- 班前会 5 分钟点评昨日数据（反馈）
- 把"数据准确率"纳入班组考核（结果）
- 缺料信息自动推到计划员手机（任务支持）
- 关键岗位配备份人选（风险）

## 反模式

| 说法 | 问题 |
|---|---|
| "员工素质不行，培训一下" | 跳过 ①–④，把系统问题推给个人 |
| "上了系统就好了" | 系统只改工具，不改标准/奖励/反馈 |
| "加钱就行" | 若 ①②④ 缺失，加钱只买到短期服从 |
| "他们抵触变革" | 先问"变革后他的活变重了吗、考核变了吗" |
