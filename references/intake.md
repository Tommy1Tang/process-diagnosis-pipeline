# 信息采集：问什么、怎么问、缺了怎么办

## 一、8 项必填（按顺序问，一次最多 3 个）

| # | 问题（可直接照读） | 追问 | 记成什么 |
|---|---|---|---|
| 1 | 你们做什么产品/服务，大概多少人、几个厂/几个点？ | 是离散制造、流程制造还是服务？ | 行业 + 规模 + 生产类型 |
| 2 | 现在最痛的三个现象是什么？用你们自己的话说。 | 最近一次是什么时候？影响了谁？ | 3 条症状原话 |
| 3 | 这次想解决的是哪条流程？从哪开始、到哪结束？ | 谁触发？什么算结束（客户签收/收款/设备复机）？ | 流程名 + 触发点 + 终点 |
| 4 | 这条流程经过哪些部门？用了哪些系统？ | SAP 哪些模块？还有 Excel 吗？ | 部门清单 + 系统清单 |
| 5 | 现在能量到的数字有哪些？（交期、合格率、停机、库存…） | 谁在统计？多久出一次？ | 指标 + 口径 + 频率 |
| 6 | 这件事谁掏钱、谁拍板、谁的考核会因此变化？ | 他上次为什么愿意/不愿意投？ | 决策人 + 利益相关方 |
| 7 | 以前试过什么办法？为什么没成？ | 是没做，还是做了没用？ | 历史失败清单 |
| 8 | 希望多久见效？怎么算成功？ | 验收会看哪几个数？ | 时间窗 + 验收方式 |

**规则**
- 用户已经说过的不要重复问；能从上下文推断的写成"推定：…，对吗？"
- 一次只问 3 个，问完就产出点东西（哪怕是一张草表），别让对话变成审讯。
- 用户答不上来时，给选项（"是 A 还是 B？"），不要留空白。

## 二、按角色的深访清单（阶段 2 用）

**老板/总经理（20 分钟）**
1. 今年最想改的三个数是哪三个？
2. 如果只能改一条流程，你选哪条？为什么不是别的？
3. 这条流程上，你觉得最冤的一次损失是什么？
4. 谁对这条流程负总责？他有权调人调钱吗？

**部门经理（30 分钟）**
1. 你部门交给下游的东西，最常被投诉什么？
2. 上游给你的东西，最常缺什么？
3. 你部门考核哪几个数？这些数会不会让你做"对自己好、对整体不好"的选择？
4. 跨部门吵架，最后谁拍板？多久能拍一次？

**一线/班组长（30 分钟，去工位）**
1. 这件活你一天做几次？中间被打断几次？
2. 要开几个系统/几张单？有没有一件事要录两遍？
3. 做错了，多久能知道？谁会告诉你？
4. 做得快、做得好，有什么好处？会不会反而多干活？
5. 如果让你删掉一个步骤，你删哪个？

**IT/系统管理员（20 分钟）**
1. 哪些数据是系统里有的，哪些还在 Excel/纸上？
2. 主数据谁维护？多久对一次？
3. 报表是系统出还是人手拼？出一次要多久？

## 三、最小数据集（按行业给默认值）

**离散制造**：订单交付周期（承诺/实际）、计划达成率、齐套率、一次合格率、返工率、OEE、停机小时、MTTR/MTBF、在制库存、成品周转天数、加急单占比。

**流程制造**：批次合格率、收率、切换清洗时间、非计划停机、能耗单耗、批次追溯完整率。

**服务/交付型**：响应时长、首次解决率、返工率、人均处理量、客户满意度、SLA 违约次数。

> 一个都没有也能做：用访谈估一个区间（如"大概 20–30 天"），标 `[估算]`，并在阶段 5 给采集方案。

## 四、缺数据的降级规则

| 情况 | 处理 |
|---|---|
| 完全没有数 | 用"访谈估算 + 抽 10 单人工复核"建基线，标 `[估算]` |
| 有数但口径不一 | 先定口径（起止点、含不含返工），把旧数标 `[口径待统一]` |
| 有数但不敢给 | 只做相对值（改善前后对比），不做绝对值承诺 |
| 数据在系统里取不出 | 列"取数需求单"：字段、表、频率、责任人、上线时间 |

## 五、开工门禁（三问）

1. 指标能量化吗？（哪怕是估算区间）
2. 流程边界说得清吗？（触发点 + 终点）
3. 有一个会被考核的负责人吗？

任何一项"不知道" → 写进 `01_方向.md` 的"风险与假设"，并说明补法；**不要假装知道**。
