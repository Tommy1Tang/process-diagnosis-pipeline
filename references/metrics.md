# 指标链：M1 / M2 / M3 与基线

## 一、三层指标

| 层级 | 定义 | 谁来定 | 例子 |
|---|---|---|---|
| **M1** | 流程末端、客户能感知的结果 | 流程责任人 + 客户 | 准时交付率、订单交付周期、一次合格率 |
| **M1-外** | 纯客户视角 | 客户 | 客诉数、退货率、到货破损率 |
| **M1-内** | 客户 + 经营双视角 | 管理层 | 上市首年毛利、单均履约成本 |
| **M2** | 子流程末端 | 子流程 owner | 齐套率、换型时间、检验周期 |
| **M3** | 关键步骤产出 | 班组长 | 首件合格、报工及时率 |

**收敛规则**：只保留与某条 M1 有因果关系的 M2；M3 只给"流程成败所系"的少数步骤。
**自检**：这条 M2 变好，M1 会变好吗？答不出因果 → 删。

## 二、指标开发四步（三层通用）

1. 选出最重大的 3–5 个产出。
2. 选关键维度：质量（准确/可靠/一致）、生产率（数量/及时性）、成本（人工/材料/营运）。
3. 每个维度配 1–2 个可计算指标。
4. 设目标值（客户要求 / 组织要求 / 标杆）。

## 三、口径必须写死（否则验收必吵）

每条指标写七要素：**名称｜定义｜分子分母｜起止点｜数据源｜频率｜责任人**。

例：
- 准时交付率 = 按承诺日交付订单数 ÷ 总交付订单数；起止：订单确认 → 客户签收；数据源：SAP 交货单 + 签收记录；频率：周；责任人：交付流程 owner。
- 口径陷阱：按"承诺日"还是"客户要求日"？含不含客户改期？部分交付算不算？——**先吵清楚，再写进合同。**

## 四、常用指标库（制造业）

| 指标 | 算法 | 常见坑 |
|---|---|---|
| 准时交付率 OTD | 准时单数 / 总单数 | 承诺日可被销售放宽 → 同时看"承诺偏差" |
| 交付周期 LT | 签收时间 − 下单时间 | 只算工作日，掩盖排队 |
| 计划达成率 | 实际产出 / 计划产出 | 计划本身可被调低 → 配"计划变更次数" |
| 齐套率 | 齐套工单 / 下达工单 | 齐套定义（几成料算齐）要先定 |
| 一次合格率 FPY | 一次通过数 / 投入数 | 返工后合格算不算？必须排除 |
| OEE | 可用率 × 性能 × 合格率 | 口径差异极大，必须写三项分解 |
| MTTR / MTBF | 平均修复时间 / 平均故障间隔 | 停机起止由谁记？事后补录不可信 |
| 库存周转 | 销货成本 / 平均库存 | 呆滞料是否计入 |
| COPQ | 报废+返工+索赔+检验 | 常被漏算的是"隐性返工" |

## 五、防撞车三问

1. 这个指标会不会让某部门"自己漂亮、下游遭殃"？（仓库装载率 vs 交付及时率）
2. 有哪个指标与它方向相反？（产量 vs 换型柔性；检验严格 vs 交付速度）
3. 它能不能追到某条 M1？追不到就删。

**发现撞车时**：把部门指标改成"流程贡献指标"（如仓库考核"按客户要求日发运达成率"，而不是装载率）。

## 六、基线怎么定（没有基线不许承诺收益）

| 情况 | 做法 |
|---|---|
| 有系统数据 | 取近 6–12 个月，剔除异常月，算均值 + 波动区间 |
| 只有月报 | 用月报均值，标注"月度粒度" |
| 完全没有 | 抽 20–30 单人工复盘，估区间，标 `[估算]` |
| 口径混乱 | 先统一口径，旧数据标 `[口径待统一]`，不用于承诺 |

**基线五要素**：值、区间、口径、时间段、数据源。缺一项就不能写进合同。

## 七、目标怎么设

- 内部改进：基线 + 行业对标 + 可达性（先定 6 个月目标，再定 12 个月）。
- 对外承诺（按结果收费）：**只承诺你能控制的指标**，且写清"因客户原因导致的偏差如何剔除"。
- 三段式写法：`基线 78% → 6 个月 88% → 12 个月 95%，口径见附件，数据源 SAP，季度核算`。

## 八、验收条款模板（FDE/对赌场景）

1. 指标与口径（附定义表）
2. 基线值与采集方式（谁采、何时采、争议怎么裁）
3. 目标值与时间窗（分阶段）
4. 数据源与访问权限
5. 排除项（客户停机、需求变更、数据未提供）
6. 未达标处理（补做/扣款/延期）
7. 超额奖励（可选）
8. 终止条件

> 一句话：**没写进口径表的指标，验收时一定吵。**
